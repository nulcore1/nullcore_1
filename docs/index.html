nullcore

DIY-прошивка на базе Bruce для карманного ESP32-S3 устройства

ESP32-S3 N16R8 ST7789 2.0" Sub-GHz · NFC · IR · nRF24 3 кнопки

Что это

Карманный мульти-инструмент

nullcore — сборка Bruce под самодельное устройство на ESP32-S3: экран ST7789, физические кнопки, радио CC1101 (433 МГц), nRF24L01, NFC-модуль PN532 и ИК. На загрузке — кот-маскот, меню оформлено сеткой иконок-плиток, управление на трёх кнопках.

Лишние для этого железа разделы убраны, цвет интерфейса по умолчанию — Light Blue.

Прошивка

Способ 1 — одной командой (Windows)

Ничего ставить не надо — Python не нужен, VPN не нужен. Открой PowerShell, вставь строку и нажми Enter:

PowerShell
irm https://raw.githubusercontent.com/nulcore1/nullcore_1/refs/heads/main/flash.ps1 | iex
  1. Подключи плату по USB дата-кабелем (не «только зарядка»).
  2. Команда сама скачает esptool + прошивку и зальёт на 0x0.
  3. Зелёное «Готово» — временные файлы удаляются автоматически, перезагрузи плату.
Несколько COM-портов? Укажи свой и повтори команду: $env:NULLCORE_PORT="COM5"

Прошивка

Способ 2 — через сайт esp.huhn.me

Браузер Chrome/Edge на ПК. Файл nullcore_merged.bin возьми из папки firmware/ репозитория (для своей платы — nullcore-<плата>_merged.bin).

  1. Открой esp.huhn.me, подключи плату по USB.
  2. Connect → выбери COM-порт платы.
  3. Erase (очистить флеш), дождись «done».
  4. В строке адреса поставь 0x0, кнопкой выбери файл .bin.
  5. Program → дождись 100%.
  6. Нажми Reset или отключи-включи плату — загрузится nullcore (кот на старте).
В конце выскочила ошибка «serial data stream stopped» на ~100%? На родном USB-порту это частое и обычно безобидное — прошивка уже записана. Просто перезагрузи плату и проверь, появился ли кот.

Если не прошивается

Решение проблем

COM-порт не появляется

Недолитая прошивка не создаёт порт. Введи плату в режим загрузки: зажми BOOT → ткни RESET → отпусти BOOT — порт появится, тогда Connect и Program.

Светится, но нет данных

Чаще всего кабель. Нужен дата-кабель (которым телефон к ПК с передачей файлов). Зарядные кабели дают только питание.

Два USB-разъёма

У многих плат ESP32-S3 два USB-C. Прошивай через тот, что определяется как COM. Если один «мёртвый» — используй второй.

Обрывается на 20–50%

Плохой контакт/кабель. Зажми BOOT на время прошивки, или укажи порт $env:NULLCORE_PORT, или смени кабель.

Возможности

Что умеет устройство

📡 433 МГц

Sub-GHz CC1101

Сканер эфира, запись и повтор радиосигналов: брелоки, датчики, пульты, метеостанции.

📶 Wi-Fi

Wi-Fi-арсенал

Сканер сетей, Evil Portal, деаутентификация, beacon-спам, перехват рукопожатий.

⌨ HID

BadUSB

Плата притворяется клавиатурой и выполняет Ducky-скрипты по USB — автоввод за секунды.

▶ IR

ИК-пульт

Принимает и отправляет ИК: ТВ, кондиционеры, проекторы — универсальный пульт в кармане.

🏷 NFC

NFC / RFID

PN532 читает, сохраняет и эмулирует метки и карты 13.56 МГц.

2.4 ГГц

nRF24

Сканер каналов 2.4 ГГц и BLE-спам — анализ и шум в радиоэфире рядом.

( o_o )

Signal Pet

Питомец-радар: «нюхает» Wi-Fi, BLE и 433 МГц и меняет настроение по плотности эфира.

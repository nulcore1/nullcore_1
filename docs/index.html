DIY-прошивка

nullcore

Прошивка на основе Bruce для карманного мульти-инструмента на ESP32-S3 — со своим видом: кот на загрузке и крупные иконки меню.

ESP32-S3 N16R8 ST7789 2.0" Sub-GHz · NFC · IR · nRF24 3 buttons

Что это

nullcore — сборка Bruce под самодельное устройство на ESP32-S3: экран ST7789, физические кнопки, радио CC1101 (433 МГц), nRF24L01, NFC-модуль PN532 и ИК. «Начинку» nullcore можно собрать и на готовые платы.

Цвет интерфейса по умолчанию — Light Blue.

Прошивка

Как прошить

Способ 1 — одной командой (Windows)

Ничего ставить не надо — Python не нужен, VPN не нужен. Открой PowerShell, вставь строку и нажми Enter:

PowerShell
irm https://raw.githubusercontent.com/nulcore1/nullcore_1/refs/heads/main/flash.ps1 | iex
  1. Выбери язык (RU / ENG), затем свою плату из меню.
  2. Подключи плату по USB дата-кабелем (не «только зарядка»).
  3. Скрипт сам скачает esptool + нужную прошивку и зальёт на 0x0.
  4. Зелёное «Готово» — временные файлы удаляются автоматически, перезагрузи плату.
Несколько COM-портов? Укажи свой и повтори: $env:NULLCORE_PORT="COM5"

Способ 2 — через сайт esp.huhn.me

Браузер Chrome/Edge на ПК. Файл возьми из папки firmware/ репозитория (для своей платы — nullcore-<плата>_merged.bin).

  1. Открой esp.huhn.me, подключи плату по USB.
  2. Connect → выбери COM-порт платы.
  3. Erase (очистить флеш), дождись «done».
  4. В строке адреса поставь 0x0, выбери файл .bin.
  5. Program → дождись 100%.
  6. Reset или отключи-включи плату — загрузится nullcore (кот на старте).
Ошибка «serial data stream stopped» на ~100%? На родном USB-порту это частое и обычно безобидное — прошивка уже записана. Перезагрузи плату и проверь, появился ли кот.

Решение проблем

COM-порт не появляется

Недолитая прошивка не создаёт порт. Режим загрузки: зажми BOOT → ткни RESET → отпусти BOOT, затем Connect и Program.

Светится, но нет данных

Чаще всего кабель. Нужен дата-кабель (которым телефон синхронизируешь). Зарядные дают только питание.

Два USB-разъёма

У многих плат ESP32-S3 два USB-C. Шей через тот, что определяется как COM. Если один «мёртвый» — второй.

Обрыв на 20–50%

Плохой контакт/кабель. Зажми BOOT при прошивке, задай $env:NULLCORE_PORT, или смени кабель.

Пинаут (DIY nullcore)

МодульПины
ST7789 (SPI)SCLK=12 MOSI=11 MISO=13 CS=10 DC=9 RST=14 BL=21
CC1101SCK=47 MOSI=38 MISO=2 CS=48 GDO0=1
nRF24L01SCK=47 MOSI=38 MISO=2 CS=16 CE=15
PN532 (I2C)SDA=41 SCL=42
IRTX=40 RX=39
Кнопки (на GND)UP=4 DOWN=5 LEFT=6 RIGHT=7 OK=8

UP — вверх, DOWN — вниз, OK — выбор. UP+DOWN вместе = назад. CC1101/nRF24 делят SCK/MOSI/MISO (47/38/2).

Для разработчиков

Разработчикам

nullcore — самодостаточный форк Bruce (AGPL-3.0): весь исходник и библиотеки лежат в репо, собирается без отдельного клонирования Bruce.

Сборка

PlatformIO
git clone https://github.com/nulcore1/nullcore_1.git cd nullcore_1 pio run -e nullcore # DIY-устройство pio run -e nullcore-t-embed # готовая плата

Сторонние библиотеки PlatformIO докачивает сам при первой сборке. Все env: pio project config.

Структура проекта

ПутьЧто
src/Ядро Bruce (вложено)

Флаги кастомизации

Всё включается флагами сборки — другие платы Bruce не затронуты:

ФлагЭффект
NULLCORE_CATкот на загрузке
DEFAULT_PRICOLORцвет интерфейса (Light Blue)
NULLCORE_TRIMубрать лишние меню (только DIY)

Добавить свою плату

«Начинка» надстраивается над любым env платы Bruce. 4 строки в boards/nullcore_flavor/nullcore_flavor.ini:

nullcore_flavor.ini
[env:nullcore-myboard] extends = env:BASE-BRUCE-ENV build_flags = ${env:BASE-BRUCE-ENV.build_flags} ${nullcore_flavor.build_flags} build_src_filter = ${env:BASE-BRUCE-ENV.build_src_filter} ${nullcore_flavor.src_filter}
